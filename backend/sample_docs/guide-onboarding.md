# Guide d'onboarding — Nordelia (entreprise fictive)

## Bienvenue
Nordelia est une société de conseil en ingénierie logicielle fictive, utilisée pour la démonstration de DocuChat. Ce guide présente les étapes de votre première semaine.

## Première journée
Votre manager vous accueille à 9h30 à l'accueil du siège. Vous recevez votre ordinateur portable, votre badge d'accès et vos identifiants. Le service informatique active votre compte de messagerie et votre accès au VPN dans la matinée.

## Outils internes
- Messagerie et agenda : suite collaborative de l'entreprise.
- Gestion de projet : tableau Kanban partagé par équipe.
- Dépôt de code : forge Git interne, avec revue de code obligatoire avant chaque fusion.
- Assistant documentaire : DocuChat, pour poser des questions sur les documents internes.

## Parrainage
Chaque nouvel arrivant est accompagné par un parrain pendant ses trois premiers mois. Un point hebdomadaire de 30 minutes est organisé avec le parrain.

## Formation
Une formation de 10 semaines est proposée aux jeunes diplômés. Elle couvre le développement backend, le cloud, le DevOps et les bonnes pratiques de sécurité.
