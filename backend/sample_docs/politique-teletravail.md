# Politique de télétravail — Nordelia

## Principe
Le télétravail est ouvert à tous les salariés après la fin de la période d'essai. Les stagiaires peuvent télétravailler avec l'accord de leur tuteur.

## Nombre de jours
Chaque salarié peut télétravailler jusqu'à 2 jours par semaine. Les jours de télétravail sont fixés avec le manager et indiqués dans l'agenda partagé. Le mercredi est un jour de présence obligatoire pour toutes les équipes.

## Indemnité
Une indemnité de télétravail de 2,50 euros par jour télétravaillé est versée chaque mois, dans la limite de 22 jours par mois.

## Équipement
L'entreprise fournit un écran externe, un clavier et une souris sur demande. Le salarié doit disposer d'une connexion internet stable et utiliser le VPN pour accéder aux ressources internes.

## Sécurité
Il est interdit de travailler sur des données confidentielles depuis un lieu public. L'écran doit être verrouillé à chaque absence.
